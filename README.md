# Bangkok Ice Run

A lightweight top-down 32-bit-style Bangkok delivery game prototype.

## Play
Open `index.html` in a browser or serve the repository as a static site.

## Controls
- Desktop: Arrow keys / WASD
- Brake: Space
- Mobile: On-screen D-pad and brake button

## Current prototype
- Bangkok Chinatown-inspired map
- Chao Phraya river edge
- Shrines and market stalls
- Traffic collisions
- 3 delivery checkpoints
- Ice that melts continuously and spills behind the bike
- Mobile controls
